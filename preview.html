Why some rows are greyed

verified means the game returned a record for that ID at load. not on this build means it did not, and the button is disabled rather than firing into nothing.

Existing still does not mean correct. Items.ma_wat_lch_06_onscreen_01 resolves and reads fine, but the list calling it "Where the Bodies Hit the Floor" had the wrong district. The two real shards are under wat_nid_03, one named go_clean_after_elly, which guessing from the title would never reach.

Fixed after checking the official wiki

  1. Ammo was under the wrong prefix. Shipped as Items.HandgunAmmo, actually Ammo.HandgunAmmo. All five rows would have loaded greyed out.
  2. The unstuck teleport used a deprecated call. Now routed through the teleportation facility with a real Vector4.
  3. Perk and attribute points were renamed at patch 2.0. Game.GiveDevPoints and Game.SetAttribute are gone; this uses the current PlayerDevelopmentSystem route.
  4. Street cred through Game.SetLevel is undocumented, so the button was removed rather than left looking official.

What was taken out, and why

  1. Force complete the tracked quest. It wrote a journal state with no previous value to restore, and the enum names did not resolve on this build, so it fell back to hard-coded numbers. A wrong number there is a permanently wrong quest.
  2. Story facts. Johnny's relationship level, Skippy's mode, the Takemura flag. Undoing the fact does not undo what the story already did because of it.
  3. Teleport is gated, not removed. Several destinations cannot be left on foot, so the known-place buttons stay disabled until a waypoint exists to return to.
  4. Nothing beneficial was removed. Eddies, points, ammo, components, medkits, levels, attributes, vehicles and the browser are all intact.

Still open

F2 is unbound. CET forbids mods from shipping default keys. Overlay, Bindings, "Fixer: show menu", press F2, Save.

Weather names are unverified. The official wiki documents no weather commands, so those eight strings stay community guesses. The system call is probed; the names are not.
